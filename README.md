# GreenMart – Online Grocery Shop

GreenMart is a simple PHP & MySQL web application for an online grocery store.

## Features
- View products from a MySQL database
- Product images
- Categories and pricing
- Stock management

## Technologies Used
- PHP
- MySQL
- XAMPP (Apache & MySQL)
- HTML & CSS

## Installation
1. Install XAMPP
2. Copy the project folder to:
   C:\xampp\htdocs\greenmart
3. Start Apache and MySQL
4. Import the database using phpMyAdmin
5. Open browser and go to:
   http://localhost/greenmart
